# Templates

A small set of exceptional templates rather than a large set of mediocre ones.

Each directory is one document mode. `essay/` ships first (Milestone 2);
`memo/`, `report/` and `rfc/` follow. Templates own typography, heading
hierarchy, page geometry, footnotes, references, tables, figures, code, page
numbering, widows/orphans and page breaks — the manuscript never changes when
the template does.
